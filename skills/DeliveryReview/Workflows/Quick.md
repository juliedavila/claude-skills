# Quick Workflow

A fast read of one artifact, for when the user wants a first take or has limited time.

## Steps

1. Read the artifact fully (`Intake.md` for type handling; still read deck notes).
2. Write a three-line proposal map: problem, change, decision asked.
3. Skim `Lenses.md` and pick the three lenses that bite hardest.
4. Return, in chat (no file unless asked):
   - **Overall read:** two or three sentences.
   - **Keep:** the top three strengths, each with a citation and a reason.
   - **Fix:** up to five holes, ranked, each as one line of concern plus one line of suggestion, with a citation.
   - **The question:** the single question whose answer would most change the assessment.
5. Offer the full Review workflow if the holes suggest the package needs it.
